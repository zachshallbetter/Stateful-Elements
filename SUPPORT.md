# Support

Stateful Elements is maintained by one person. This page says what that means in practice.

- **Questions and bugs:** open a [GitHub issue](https://github.com/zachshallbetter/Stateful-Elements/issues/new/choose).
  Use the bug report or feature request form so the maintainer has what is needed to act.
- **Response time:** best-effort, with no SLA. Nobody is on call, and a reply can take a while.
- **Security reports:** do not open a public issue. Follow [`SECURITY.md`](SECURITY.md), which uses
  GitHub private vulnerability reporting.
- **Versioning:** The package is `stateful-elements` at version 1.0.0 (see `package.json` and the `v1.0.0` tag). It is not published to npm.
